ogp-break-lint

自分のタイトルを入れて、OGP画像での折れ方を試せます。

GitHub README

入力

利用幅 = 幅 − 余白 × 2 = 1040 px

word-break は Satori / CSS と同じです。normal が既定、break-all は1文字ずつ、keep-all は単語境界です。その他の既定値（幅 1200px、余白 80px、フォント 64px、最大 3 行）も CLI と同じです。

折り位置の計算は、CLI の既定と同じく Noto Sans JP Regular の推定幅とカーニング表を使っています。エンジンとメトリクスはページに同梱してあり、入力はブラウザの外に出ません。

    
実フォントや Satori の描画とは差が出ることがあります。表示用に読み込んでいる Noto Sans JP と、計算に使っているメトリクスでも、カーニングの入り方などで見た目の幅が数 px ずれることがあります。
